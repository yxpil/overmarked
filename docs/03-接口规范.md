# OVERMARKED 接口规范

版本 1.0 · 2026-10-22 · Base URL: `http://<host>:8787/api`

---

## 1. 通用约定

### 1.1 协议与编码

- HTTP/1.1；请求与响应均为 UTF-8。
- JSON 接口：`Content-Type: application/json`。
- 上传接口：原始字节流（非 multipart），文件名经查询参数传递。
- 时间：ISO-8601 UTC 字符串，如 `2026-10-22T09:30:00.000Z`。
- ID：UUID v4 字符串；条目另有项目内序号 `seq`（整数，从 1 开始）。

### 1.2 认证

- 登录成功后服务端设置 Cookie：`om_session=<opaque>; HttpOnly; SameSite=Strict; Path=/`。
- 浏览器自动携带；脚本调用需保存并回传该 Cookie。
- 除 `GET /api/health`、`POST /api/auth/login` 外，所有接口要求有效会话，否则 `401 UNAUTHENTICATED`。

### 1.3 CSRF

所有 `POST / PUT / PATCH / DELETE` 请求必须携带：

```
X-OM-Request: 1
```

缺失返回 `403 CSRF_BLOCKED`。

### 1.4 错误格式

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "name 不能为空",
    "details": { "field": "name" }
  }
}
```

| HTTP | code | 含义 |
|---|---|---|
| 400 | `BAD_REQUEST` | 请求格式错误（非法 JSON 等） |
| 401 | `UNAUTHENTICATED` / `INVALID_CREDENTIALS` | 未登录 / 账号密码错误 |
| 403 | `FORBIDDEN` / `CSRF_BLOCKED` / `ACCOUNT_DISABLED` | 无权限 / 缺 CSRF 头 / 账号被停用 |
| 404 | `NOT_FOUND` / `FILE_MISSING` | 资源不存在 / 记录存在但文件缺失 |
| 409 | `CONFLICT` / `INVALID_STATE` / `LABEL_IN_USE` / `ITEM_APPROVED` | 唯一冲突 / 状态不允许 / 标签被引用 / 已通过条目 |
| 413 | `PAYLOAD_TOO_LARGE` | 请求体或文件超限 |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | 扩展名不属于该项目类型 |
| 422 | `VALIDATION_ERROR` | 字段或标注数据校验失败 |
| 429 | `RATE_LIMITED` | 登录尝试过多，响应含 `Retry-After` |
| 500 | `INTERNAL` / `STORAGE_ERROR` | 未预期错误 / 磁盘写入失败 |
| 503 | `DB_BUSY` | 数据库忙，可重试 |

错误响应不包含堆栈。

### 1.5 分页

列表接口参数：`page`（默认 1）、`limit`（默认 50，最大 200）。

```json
{ "items": [], "page": 1, "limit": 50, "total": 0 }
```

### 1.6 角色缩写

- `admin`：系统管理员。
- `manager` / `reviewer` / `annotator`：项目角色。
- "成员" = 项目内任意角色。"管理" = admin 或 manager。"复核" = admin / manager / reviewer。

## 3. 认证

### POST /api/auth/login

公开。登录并创建会话。失败限流：10 分钟 8 次（IP + 用户名）。

请求：

```json
{ "username": "admin", "password": "secret" }
```

响应 `200`：

```json
{
  "user": {
    "id": "6f1c...", "username": "admin", "displayName": "管理员",
    "role": "admin", "status": "active",
    "createdAt": "2026-10-22T08:00:00.000Z", "lastLoginAt": "2026-10-22T09:30:00.000Z"
  }
}
```

错误：`401 INVALID_CREDENTIALS`（用户不存在/密码错误统一）、`403 ACCOUNT_DISABLED`、`429 RATE_LIMITED`。

`curl -c jar.txt -H 'Content-Type: application/json' -H 'X-OM-Request: 1' -d '{"username":"admin","password":"..."}' http://127.0.0.1:8787/api/auth/login`

### POST /api/auth/logout

需登录。删除当前会话并清除 Cookie。响应 `204`。

### GET /api/auth/me

需登录。返回当前用户。

```json
{ "user": { "id": "...", "username": "...", "displayName": "...", "role": "user", "status": "active", "createdAt": "...", "lastLoginAt": "..." } }
```

### POST /api/auth/password

需登录。修改自己的密码，成功后该用户全部会话失效（包括当前），需重新登录。

```json
{ "currentPassword": "old", "newPassword": "new-strong-pass" }
```

响应 `204`。错误：`401 INVALID_CREDENTIALS`（当前密码错）、`422`（新密码不符合 8..128）。

## 4. 用户管理（admin）

### GET /api/users

查询参数：`q`（用户名/显示名模糊）、`status`。

```json
{
  "users": [
    { "id": "...", "username": "alice", "displayName": "Alice", "role": "user",
      "status": "active", "createdAt": "...", "lastLoginAt": "..." }
  ]
}
```

### POST /api/users

```json
{ "username": "alice", "displayName": "Alice", "password": "password123", "role": "user" }
```

- `username`：3..32，`^[a-zA-Z0-9_.-]+$`，不区分大小写唯一。
- `displayName`：1..40。
- `password`：8..128。
- `role`：`admin | user`，默认 `user`。

响应 `201 { "user": {...} }`。错误：`409 CONFLICT`（用户名重复）。

### PATCH /api/users/:id

```json
{ "displayName": "Alice W.", "role": "admin", "status": "disabled", "password": "reset-pass-123" }
```

字段均可选。设置 `status=disabled` 或重置密码会吊销该用户全部会话。不能停用/降级最后一个 active admin（`409 CONFLICT`）。响应 `200 { "user": {...} }`。

### GET /api/directory?q=

任何登录用户可用，用于成员选择器。仅返回 active 用户的公开字段：

```json
{ "users": [ { "id": "...", "username": "alice", "displayName": "Alice" } ] }
```

限制返回 20 条。

## 5. 项目

### GET /api/projects

返回当前用户可见项目（admin 全部；其他为成员项目）。参数：`kind`、`archived=1|0`。

```json
{
  "projects": [
    {
      "id": "...", "name": "街景目标检测", "description": "第一版",
      "kind": "image", "archived": false,
      "role": "manager",
      "labelsCount": 6,
      "counts": { "total": 120, "pending": 50, "in_progress": 10,
                  "submitted": 20, "approved": 35, "rejected": 5 },
      "createdAt": "...", "updatedAt": "..."
    }
  ]
}
```

### POST /api/projects

任何登录用户可创建；创建者成为 manager。

```json
{
  "name": "街景目标检测",
  "kind": "image",
  "description": "可选",
  "labelSchema": { "labels": [ { "id": "lb_1", "name": "车辆", "color": "#f5a524", "hotkey": "1" } ] }
}
```

`kind` ∈ `image | text | audio | spatial`；`labelSchema` 可省略，服务端按类型生成默认标签。响应 `201 { "project": {...} }`。

### GET /api/projects/:id

成员（或 admin）。返回项目、当前用户角色与统计概览、成员。

```json
{
  "project": {
    "id": "...", "name": "...", "description": "", "kind": "text",
    "archived": false, "labelSchema": { "labels": [], "documentLabels": [] },
    "createdBy": "...", "createdAt": "...", "updatedAt": "..."
  },
  "role": "annotator",
  "counts": { "total": 3, "pending": 1, "in_progress": 0, "submitted": 1, "approved": 1, "rejected": 0 },
  "members": [
    { "userId": "...", "username": "bob", "displayName": "Bob", "role": "manager", "createdAt": "..." }
  ]
}
```

### PATCH /api/projects/:id

管理权限。可改 `name`、`description`、`labelSchema`、`archived`。

- 删除仍被标注引用的标签 → `409 LABEL_IN_USE`，`details.count` 为引用条数。
- `archived=true` 后普通成员只读（写接口返回 `409 PROJECT_ARCHIVED`）。

响应 `200 { "project": {...} }`。

### DELETE /api/projects/:id

管理权限。必须提供确认体：

```json
{ "confirmName": "街景目标检测" }
```

名称不匹配 → `422`。删除项目、条目、标注、成员关系与本地文件。响应 `204`。

### 5.1 成员

#### GET /api/projects/:id/members

成员可读。

```json
{ "members": [ { "userId": "...", "username": "bob", "displayName": "Bob",
                 "role": "reviewer", "createdAt": "..." } ] }
```

#### POST /api/projects/:id/members

管理权限。

```json
{ "userId": "...", "role": "annotator" }
```

`role` ∈ `manager | reviewer | annotator`。目标用户必须 active。响应 `201 { "member": {...} }`。重复添加 → `409 CONFLICT`。

#### PATCH /api/projects/:id/members/:userId

管理权限。`{ "role": "reviewer" }`。不得移除/降级最后一名 manager（`409 CONFLICT`）。响应 `200 { "member": {...} }`。

#### DELETE /api/projects/:id/members/:userId

管理权限。不能移除最后一名 manager。响应 `204`。

### 5.2 统计

#### GET /api/projects/:id/stats

成员可读。结构见详细设计 7.6：

```json
{
  "total": 120,
  "byStatus": { "pending": 50, "in_progress": 10, "submitted": 20, "approved": 35, "rejected": 5 },
  "approvedPct": 29.2,
  "annotators": [ { "userId": "...", "name": "Alice", "annotated": 40, "approved": 38 } ],
  "labels": [ { "labelId": "lb_1", "name": "车辆", "count": 133 } ],
  "trend": [ { "date": "2026-10-21", "submitted": 12, "approved": 9 } ]
}
```

### 5.3 项目审计

#### GET /api/projects/:id/audit?limit=100

管理权限。返回最近审计（倒序，≤ 500 条）。

```json
{ "entries": [ { "id": 42, "actorId": "...", "actorName": "Bob", "action": "review.approve",
                 "entity": "item", "entityId": "...", "detail": { "note": "ok" },
                 "ip": "127.0.0.1", "createdAt": "..." } ] }
```

## 6. 条目

### GET /api/projects/:id/items

成员可读。参数：

| 参数 | 说明 |
|---|---|
| `status` | `pending|in_progress|submitted|approved|rejected`，可逗号分隔多个 |
| `q` | 文件名模糊（`%` `_` 按字面匹配） |
| `assignee` | `me` 或用户 id |
| `page` / `limit` | 分页 |

响应为紧凑条目（不含标注数据）：

```json
{
  "items": [
    { "id": "...", "seq": 1, "filename": "street-01.png", "mime": "image/png",
      "size": 182734, "meta": { "width": 900, "height": 600 },
      "status": "approved", "assigneeId": null, "assigneeName": null,
      "annotationStatus": "approved", "annotationVersion": 3,
      "updatedAt": "..." }
  ],
  "page": 1, "limit": 50, "total": 120
}
```

### POST /api/projects/:id/items?filename=<urlencoded>

成员且项目未归档。请求体 = 文件原始字节。`Content-Type` 可为任意值（服务端按扩展名判定），建议携带真实类型。`filename` 必填，需含允许的扩展名。

允许扩展名见详细设计 6.1。示例：

```bash
curl -b jar.txt -H 'X-OM-Request: 1' \
  --data-binary @street-01.png \
  'http://127.0.0.1:8787/api/projects/<id>/items?filename=street-01.png'
```

响应 `201`：条目详情（同 GET /api/items/:id，`annotation=null`）。

错误：`415 UNSUPPORTED_MEDIA_TYPE`、`413 PAYLOAD_TOO_LARGE`、`422 VALIDATION_ERROR`（GeoJSON 解析失败）。

### GET /api/items/:id

成员可读。返回条目、当前标注、复核记录（最近 20 条）、权限标记。

```json
{
  "item": {
    "id": "...", "projectId": "...", "seq": 1, "filename": "street-01.png",
    "mime": "image/png", "size": 182734,
    "meta": { "width": 900, "height": 600 },
    "status": "submitted", "assigneeId": null, "assigneeName": null,
    "uploadedBy": "...", "createdAt": "...", "updatedAt": "..."
  },
  "annotation": {
    "data": { "shapes": [], "note": "" },
    "status": "submitted", "version": 2,
    "createdBy": "...", "updatedBy": "...", "updatedByName": "Alice",
    "createdAt": "...", "updatedAt": "...", "submittedAt": "...", "reviewedAt": null
  },
  "reviews": [
    { "id": 3, "reviewerId": "...", "reviewerName": "Bob",
      "decision": "rejected", "note": "漏标车辆", "createdAt": "..." }
  ],
  "can": { "annotate": true, "review": false, "manage": false }
}
```

`annotation` 不存在时为 `null`。

### PATCH /api/items/:id

- `assigneeId`：管理可指派任意成员；成员只能指派自己（`assigneeId=<自己>`）或清空自己的指派。`null` 表示取消。
- `meta`：成员可更新白名单键（`duration`、`bounds`、`crs`、`width`、`height`）；用于客户端回填音频时长/图片尺寸/空间配准。传入对象与现有 meta 合并。
- `status`：仅管理可用，允许 `approved|rejected|submitted → in_progress`（重新打开/撤回），或 `pending → in_progress`。

```json
{ "assigneeId": "<userId>", "meta": { "duration": 12.48 } }
```

响应 `200 { "item": {...} }`。错误：`409 INVALID_STATE`、`409 ITEM_APPROVED`、`422`。

### DELETE /api/items/:id

管理权限。删除条目、标注、版本、复核记录与文件。响应 `204`。

### GET /api/items/:id/file

成员可读。返回原始文件字节。支持单段 Range：

```
Range: bytes=0-1023
→ 206 Partial Content
   Content-Range: bytes 0-1023/204800
   Accept-Ranges: bytes
```

文本/JSON 强制 `text/plain; charset=utf-8` 或 `application/json; charset=utf-8`；图片/音频返回存储 MIME。非法范围 `416`。文件缺失 `404 FILE_MISSING`。

## 7. 标注与复核

### PUT /api/items/:id/annotation

成员可写且项目未归档。已通过条目仅 manager 可修改（否则 `409 ITEM_APPROVED`）。

请求：

```json
{ "data": { "shapes": [ { "id": "...", "type": "box", "label": "lb_1", "x": 10, "y": 20, "w": 100, "h": 50 } ], "note": "" },
  "submit": false }
```

- `data`：结构随项目类型，见详细设计 3.3；`label` 必须是当前 schema 中的标签 id。
- `submit=false`：保存草稿，annotation.status=`draft`，item 进入/保持 `in_progress`（submitted/rejected 会被拉回 in_progress）。
- `submit=true`：提交复核，annotation.status=`submitted`，item.status=`submitted`，写版本快照。

响应 `200`：

```json
{
  "annotation": { "data": {...}, "status": "submitted", "version": 3, "updatedAt": "..." },
  "item": { "id": "...", "status": "submitted", "updatedAt": "..." }
}
```

错误：`422 VALIDATION_ERROR`（结构/标签/区间/文本长度）、`409 ITEM_APPROVED`、`409 PROJECT_ARCHIVED`、`413`（data > 4 MB）。

### GET /api/items/:id/history

成员可读。返回版本快照与复核记录：

```json
{
  "versions": [ { "version": 3, "status": "approved", "authorId": "...", "authorName": "Bob",
                  "createdAt": "..." } ],
  "reviews": [ { "id": 1, "reviewerName": "Carol", "decision": "approved", "note": "", "createdAt": "..." } ]
}
```

`versions` 不返回 data（节省带宽），按 version 倒序，最多 100 条。

### POST /api/items/:id/review

复核权限。条目必须为 `submitted`（已 `approved` 时仅 admin/manager 可再次复核，视为撤销通过并重新判定）。

```json
{ "decision": "approve", "note": "" }
```

- `decision`：`approve | reject`。
- `reject` 时 `note` 必填 1..2000。
- 通过：item/annotation → `approved`；驳回：→ `rejected`，标注人可修改后重新提交。

响应 `200 { "item": {...}, "annotation": {...}, "review": {...} }`。错误：`409 INVALID_STATE`、`422`。

## 8. 导出

### GET /api/projects/:id/export

成员可读（v1 导出不区分角色；成员均可下载）。参数：

| 参数 | 值 |
|---|---|
| `format` | `coco`（image）、`ner`（text）、`audio`（audio）、`geojson`（spatial）、`raw`（任意） |
| `scope` | `approved`（默认，仅通过）/ `all`（所有有标注的条目） |

`format` 与项目类型不匹配 → `422`。

响应为附件下载：

```
Content-Type: application/json; charset=utf-8   (coco/raw/geojson)
Content-Type: application/x-ndjson; charset=utf-8 (ner/audio)
Content-Disposition: attachment; filename="street-coco-20261022.json"
```

**COCO**：

```json
{
  "info": { "description": "street", "date_created": "2026-10-22T..." },
  "images": [ { "id": 1, "file_name": "street-01.png", "width": 900, "height": 600 } ],
  "annotations": [
    { "id": 1, "image_id": 1, "category_id": 1,
      "bbox": [10, 20, 100, 50], "area": 5000, "iscrowd": 0,
      "segmentation": [] }
  ],
  "categories": [ { "id": 1, "name": "车辆", "color": "#f5a524" } ]
}
```

- `image_id = item.seq`。
- box：`bbox=[x,y,w,h]`，`segmentation=[]`。
- polygon：`bbox` 为外接矩形（取整），`segmentation=[[x1,y1,x2,y2,...]]`（绝对像素）。

**NER JSONL** 每行：

```json
{"id":1,"filename":"news.txt","text":"……","entities":[{"start":3,"end":5,"label":"人物","labelId":"lb_1"}],"documentLabels":["正面"]}
```

**音频 JSONL** 每行：

```json
{"id":1,"filename":"call.wav","duration":8.0,"segments":[{"start":0.5,"end":2.1,"label":"语音","labelId":"lb_1"}]}
```

**GeoJSON**：

```json
{
  "type": "FeatureCollection",
  "name": "城市POI",
  "crs": { "type": "name", "properties": { "name": "EPSG:4326" } },
  "features": [
    { "type": "Feature",
      "geometry": { "type": "Point", "coordinates": [121.47, 31.23] },
      "properties": { "label": "lb_1", "labelName": "POI", "itemId": "...", "seq": 1, "filename": "area.geojson" } }
  ]
}
```

**raw**：

```json
{
  "exportedAt": "...",
  "project": { "id": "...", "name": "...", "kind": "image", "labelSchema": {...} },
  "items": [
    { "id": "...", "seq": 1, "filename": "...", "meta": {...}, "status": "approved",
      "annotation": { "data": {...}, "status": "approved", "version": 3, "updatedBy": "..." },
      "reviews": [ { "decision": "approved", "note": "", "createdAt": "..." } ] }
  ]
}
```

导出动作写审计 `export.download`（detail 含 format/scope/条数）。

## 10. 数据对象速查

### 10.1 User

`{ id, username, displayName, role: 'admin'|'user', status: 'active'|'disabled', createdAt, lastLoginAt }`

### 10.2 Project（详情）

`{ id, name, description, kind, labelSchema, archived, createdBy, createdAt, updatedAt }`

### 10.3 Item（详情）

`{ id, projectId, seq, filename, mime, size, meta, status, assigneeId, assigneeName, uploadedBy, createdAt, updatedAt }`

### 10.4 Annotation

`{ data, status: 'draft'|'submitted'|'approved'|'rejected', version, createdBy, updatedBy, updatedByName, createdAt, updatedAt, submittedAt, reviewedAt }`

### 10.5 LabelSchema

```json
{
  "labels": [ { "id": "lb_1", "name": "车辆", "color": "#f5a524", "hotkey": "1" } ],
  "documentLabels": [ { "id": "dl_1", "name": "正面", "color": "#7dd3fc" } ]
}
```

### 10.6 状态枚举

- 条目：`pending | in_progress | submitted | approved | rejected`
- 标注：`draft | submitted | approved | rejected`
- 项目类型：`image | text | audio | spatial`

- 客户端与服务器同仓交付，不承诺跨版本兼容。
